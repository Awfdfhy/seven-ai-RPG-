# Seven Research Source Check
1. Start from canonical documentation/repositories and check freshness, maintenance and supported versions.
2. For third-party skills, verify repository identity, license, installation method, dependencies and required permissions.
3. Distinguish official, community-maintained, forked, and merely similarly named projects.
4. Never execute installation scripts or copy code from an unknown source without inspection.
5. Record URL, date checked, compatibility, license concerns and unresolved questions.
6. Do not treat a name in a manifest as proof that an external project has been installed.
