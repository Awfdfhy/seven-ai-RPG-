# Seven UI/UX Pro Max
1. Follow existing design-system and component ownership docs before changing styles.
2. Define hierarchy, primary action, spacing, type scale, color tokens, states, and responsive behavior.
3. Prefer shared tokens/components over one-off overrides; remove duplication only when safe and tested.
4. Validate loading, empty, error, disabled, focus, pressed, and long-content states.
5. Design mobile-first for constrained Android viewports; avoid cramped controls and overflow.
6. Use meaningful RPG identity and visual atmosphere without compromising legibility or performance.
7. Compare screenshots against approved references and report objective mismatches.
