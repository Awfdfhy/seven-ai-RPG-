# Seven Performance Efficiency
1. Measure before optimizing; record device/browser, scenario, baseline and metric.
2. Prioritize startup, input-to-response latency, frame pacing, memory, network wait and long-task sources.
3. Avoid unbounded loops, duplicate listeners, repeated expensive rendering and oversized context/payloads.
4. Use progressive loading/cancellation and bounded concurrency where appropriate.
5. Test on realistic low/mid-range Android hardware; desktop-only success is insufficient.
6. Preserve correctness, narrative quality, accessibility and save integrity while optimizing.
