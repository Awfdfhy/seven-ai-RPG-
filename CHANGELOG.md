## [0.1.0] - 2026-10-26

### Added
- Initial project structure and packaging (`pyproject.toml`, `src/`, `tests/`).
- 81 source modules covering world simulation, character progression, combat, crafting, economy, storytelling, and post-game content.
- 33 JSON data files for gameplay content definitions.
- 62 test modules.
- `CHANGELOG.md` and `VERSION_INFO` for release tracking.

### Changed
- Version string unified to `0.1.0` across `pyproject.toml`, `src/__init__.py`, `src/version_info.py`, `src/main_menu_ui.py`, and release manifest.
- Release manifest generated at `release/seven-rpg-v0.1.0-manifest.json`.
- `RELEASE_NOTES.md` updated to reflect accurate module counts.
