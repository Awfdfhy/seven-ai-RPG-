# Seven RPG

A modular Python framework for text/mechanical role-playing games.

## Features

- Skill trees and progression systems
- Combat, crafting, economy, and inventory
- World map, travel, and NPC dialogue
- Party companions and AI narration
- Accessibility and difficulty settings
- Multiplayer rooms, chat, and shared-state sync via WebSocket
- Analytics, cloud sync, mod support, and community leaderboards

## Installation

```bash
pip install -e ".[dev]"
```

## Development

```bash
python -m pytest
```
